EXPERIMENTAL ONLINE DEMO

The lobby supports a host plus fifteen guests. Large groups and full campaign
playthroughs remain unverified. The first two players currently use Mickey and
Oswald respectively; additional player character choices need broader testing.
Pants colors are unique in the lobby, but appearance and nametag rendering still
need multiplayer validation across areas and character combinations.

Online uses synchronized native inputs with host corrections for player and
recognized NPC positions, velocities and health. Prediction and rollback are
unfinished. Scripts, spawning, props and combat effects can still diverge; this
is an experimental testing build, not verified full-campaign co-op. A lost peer
can stop the session. Mid-game reconnect remains unfinished. Native level entry
and shared death/respawn have passed limited two-player tests, with broader
campaign coverage still needed. Keep a backup and report where a session stops.
Host-only lethal player damage now enters the guest's native death path before
its matching update; the isolated respawn check passed. This uses generic native
damage rather than the host's full combat event. Independently generated guest
Damage events targeting admitted players are suppressed; host death replay stays
enabled. Enemy AI, lifecycle, complete combat/script replication and death paths
outside the audited native Damage dispatcher remain unfinished.

Rooms currently require an invitation. Public matchmaking and joining games
that have already started remain unfinished. Invite Friends requests Discord's
native game-invitation screen; actual cross-account acceptance still needs testing.
Discord is not the game's network transport. Copy room code remains available.

Text chat and gameplay use the room connection. Optional proximity/party voice
uses a separate authenticated relay connection with encrypted audio, bounded
queues and retries. Native component checks and the local server checks pass;
real internet audio and microphone/speaker hardware across PCs remain unverified.
Voice is Off until enabled; keep Discord voice available as a fallback.

The original Epic Mickey mode is an offline courtyard exploration preview.
Full campaign progression, quests, scripts, transitions, audio, materials,
NPC animation, collision and spawning still need compatibility work.

Higher FPS can still show animation/camera/physics issues. Start at 30 FPS.
Experimental rendering upgrades and movement abilities need broader hardware
and area coverage. Imported Rebrushed movement clips are for Mickey; Oswald
uses existing animations. Mouse aiming and solo character switching/respawns
also need additional testing.

The new native menus, mouse navigation, manual prompt sets and lobby panels
need broader physical keyboard/controller testing. A reported Epic Mickey 2
campaign-save problem has not been reproduced or claimed fixed. Keep a backup.
Startup update checks and consent are covered by mocked prerelease/download
fixtures; a newer official release is needed to verify the complete live popup
and restart path across different PCs.

For a report, include your release version, area, what each player was doing,
number of players and reproduction steps. Support & Updates prepares a bounded
local report for review before you share it. Avoid posting room codes or private
save files publicly. No report is submitted automatically.
