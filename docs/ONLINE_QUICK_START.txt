BEETLEWORX PUBLIC TESTING DEMO

Extract the complete ZIP into a writable folder and run beetleworx.exe. Setup
asks for your Epic Mickey 2 Xbox 360 disc image or extracted game folder.
Original game files are not included and stay unchanged. Keep pc-assets,
online-service.json and the supplied DLLs beside the executable.

PLAY WITH FRIENDS

Everyone needs the same Beetleworx release version and compatible game files.
Start Epic Mickey 2 and open Online Multiplayer at the title menu.

Host: select Host my save online to use your current single-player save. If you have no save yet,
start an offline game first and reach a save point, then return to the title.
The first game-file check can take several minutes; keep the menu open.
When the internet room is connected, select Copy room code and send it to your
friends. The code has eight characters. There are no router settings to change.

Guest: copy the host's room code and select Join copied room code. The host's
save is transferred into a separate online session. Choose Ready in the lobby;
the host selects Start online game when everyone is ready.

DISCORD

Run Beetleworx once to register game launching with Discord. Keep the Discord
desktop app open. After hosting, select Invite Friends in the online menu
to open Discord's game invitation screen. Choose friends or a channel there.
Copy room code is also available. Accepting an invite enters the Join flow without
copying a code. During gameplay, invites wait until you return to the title.
Joining a session that has already started is not supported in this demo.

VOICE CHAT

Open Voice chat settings in Online Multiplayer, or Player options in a lobby.
Choose Listen only, Push to talk, or Open microphone. Voice is Off initially;
new profiles use Proximity positioning when enabled. Existing choices stay saved.
The default push-to-talk key is F8; controller users hold D-pad Down.
Change proximity range, microphone, speakers and volume in the voice pages.
Nearby players are louder; other levels or unavailable player positions are muted.
Voice uses the internet relay without router configuration. It is experimental;
cross-machine hardware and long sessions still need testing.

SETUP RECOVERY

Game files and Beetleworx may be on different drives. Setup copies files when
links are unavailable, including on FAT/exFAT drives. If you select another
game folder after an interrupted setup, the previous imported view is preserved
in a pc-assets.previous-* backup beside pc-assets. Your original game and saves
are not overwritten. No fresh release extraction is required to change sources.

SETTINGS AND SAVES

Use the native Options menu for graphics, input bindings, mouse/cursor settings
and movement tuning. Start at 30 FPS; higher frame rates still need work.
Normal saves and preferences are in user_data. Online session saves are kept
separate. Back up your saves before updating.

The opening chooser also offers the original Epic Mickey courtyard preview.
It needs your Wii game image or extracted files in addition to Epic Mickey 2.
The preview is offline and the original campaign is not fully playable yet.

Use Support & Updates to review/export a diagnostic report, open a GitHub issue
draft, or check for updates. Reports are not uploaded automatically. Verified
updates install on normal exit. Extract a fresh complete ZIP if an interrupted
update leaves the game unable to start; keep your saves and original game data.
